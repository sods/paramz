# CIP-0002: Safe pickle for linked Parameterized children

## Status

- [x] Proposed
- [x] Accepted
- [x] In Progress
- [ ] Implemented
- [ ] Closed

## Summary

Finish and merge PR #50: omit `_parent_` from the pickle memento, restore observers/cache safely, add regression test, bump version. Unblock GPy #605 / #932.

## Motivation

Pickling a used child (e.g. a kernel on a GP) currently risks serializing the parent graph and failing on incomplete-object cycles.

## Detailed Description

Already implemented on branch `fix/605-pickle-used-parameterized`:

- `pickleable.py`: drop `_parent_` from memento; restore observers/cache via `object.__setattr__`.
- `parameterized.py`: harden `__setattr__` during unpickle.
- Regression test `test_pickle_linked_child_roundtrip`.
- Version bump to 0.10.1.

Remaining: merge after green CI, verify against GPy. `test_likelihood_set` failed when parent observers were not re-bound after omitting `_parent_` from the pickle memento; fixed by re-registering the pass-through observer in `_connect_parameters`.

## Implementation Plan

1. Diagnose / fix or quarantine `TestModel.test_likelihood_set` on the PR branch.
2. Re-run CI matrix; merge #50.
3. Confirm GPy #605 reproduction against the branch.
4. Close related GPy issues when released.

## Backward Compatibility

Pickled objects without `_parent_` in the memento load as detached children (expected). Cross-version pickle is still not a supported durable format.
